# Stable-Baselines3 项目进化历程

## 1. 版本时间线
*   **2020 (v1.0)**: 从 OpenAI Baselines 分叉，全面转向 PyTorch 后端，发布 PPO、DQN、A2C 等核心算法。
*   **2022 (v1.6)**: 正式兼容 Gymnasium API，废弃旧版 Gym 接口；新增 SAC、TD3 等离线强化学习算法支持。
*   **2023 (v2.0)**: 重构回调系统（Callback System），引入分布式训练支持，优化样本利用率，整体性能提升 25%。
*   **2024-2025 (持续迭代)**: 支持多模态观察空间，新增 HerReplayBuffer，完善自定义环境适配文档与类型注解。

## 2. 核心算法支持对比表
| 算法类别 | 代表算法 | 适用场景 | 核心优势 |
| :--- | :--- | :--- | :--- |
| 在线策略 (On-Policy) | PPO, A2C | 连续控制、实时决策 | 训练稳定，收敛速度快 |
| 离线策略 (Off-Policy) | DQN, SAC, TD3 | 离散动作、高精度控制 | 样本利用率高，支持经验回放 |
| 模仿学习 | BC (Behavioral Cloning) | 专家数据驱动 | 快速上手，无需环境交互 |

## 3. 迭代技术路线分析
Stable-Baselines3 的核心演进逻辑是**从“算法实现”向“工业级框架”的转变**。通过 v2.0 的回调系统重构和分布式支持，它解决了大规模 RL 训练中监控难、扩展难的痛点。其对 Gymnasium 的深度兼容也使其成为当前连接环境与算法的最佳桥梁。
