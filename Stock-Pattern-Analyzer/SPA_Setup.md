# Stock-Pattern-Analyzer 江恩量能适配与本地搭建说明

## 1. Windows 环境本地搭建步骤（适配 G 盘）
*   **第一步：源码拉取**
    将 `Stock-Pattern-Analyzer` 仓库克隆至 `G:\AI_Alchemy_System\lib\Stock-Pattern-Analyzer`。该库专注于量价时空的深层匹配，我们重点提取其量能周期识别算法。
*   **第二步：核心模块剥离**
    禁用所有形态识别（如头肩顶、双底）及交易信号生成模块，仅保留“量能循环分析”与“四方匹配验证”核心逻辑。
*   **第三步：全工具链接口验证**
    编写测试脚本，确保 TA-Lib 的量能因子、pmdarima 的时间周期、HQChart 的几何价格及 technical-analysis 的百分比位能无缝汇入本工具的加权计算层。

## 2. 版本迭代与量能优化
*   **v1.0-v1.5**: 实现了基础的成交量波动率分析，支持手动标记量能峰值。
*   **v1.6-v1.8**: 引入“量能周期自动识别模块”。模型能通过傅里叶变换或自相关分析，从历史成交量中自动提取与江恩 30/60 天时间周期同步的量能循环规律。同时升级了“量价时空匹配度计算”，将量能作为第四维度纳入共振评分体系。
