# LightGBM 项目进化历程与量化选股适配说明

## 1. 版本时间线与 CPU 优化节点
*   **2017 (v1.0)**: 微软发布 LightGBM，首创直方图算法（Histogram-based）与 Leaf-wise 生长策略。在 i5-10400 等 CPU 环境下，训练速度比 XGBoost 快 5 倍，内存占用降低一半。
*   **2020 (v3.0)**: 新增多分类任务优化及特征重要性统计功能，完美适配 A 股选股二分类任务（如：未来 3 天涨/跌）。
*   **2022-2025 (v4.0-v4.3)**: 深度优化 CPU 多核并行计算，支持千万级样本批量训练；新增早停（Early Stopping）和交叉验证机制，成为工业界量化选股的首选模型。

## 2. 与 FinRL 特征数据对接说明
| 数据组件 | FinRL 输出格式 | LightGBM 输入要求 | 对接逻辑 |
| :--- | :--- | :--- | :--- |
| **特征矩阵** | CSV/DataFrame (MACD, RSI, PE 等) | `np.ndarray` / `pd.DataFrame` | 直接读取，无需二次归一化 |
| **标签生成** | 需自定义（如：后 3 天收益率） | `0/1` 二分类整数 | 通过 `df['close'].shift(-3)` 快速计算 |
| **缺失值处理** | 自动填充 NaN | 原生支持 NaN 分裂 | 减少预处理开销，提升 CPU 效率 |

## 3. 迭代技术路线分析
LightGBM 的核心优势在于**极致的 CPU 资源利用率**。它通过直方图算法将连续特征离散化，大幅减少了 CPU 缓存未命中（Cache Miss）的情况。对于拥有 8 线程的 i5-10400，设置 `num_threads=8` 即可跑满硬件性能，实现全市场 5000 只股票的分钟级筛选。
