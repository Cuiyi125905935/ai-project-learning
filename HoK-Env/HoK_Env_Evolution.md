# HoK Env 项目进化历程

## 1. 版本时间线
*   **初始阶段 (v0.x)**: 腾讯 AI Lab 发布 Hok_env SDK，实现与《王者荣耀》游戏核心（Gamecore）的交互接口。
*   **1v1 模式成熟 (v1.0)**: 完善 1v1 强化学习环境，集成 PPO 算法训练框架，支持英雄属性、兵线信息等多模态特征输入。
*   **3v3 模式开放 (v2.0)**: 正式发布 3v3 对战环境，引入更复杂的团队协作逻辑与多智能体协同训练机制。
*   **NeurIPS 2022 论文发布**: 发表《Honor of Kings Arena: an Environment for Generalization in Competitive Reinforcement Learning》，确立了其在通用竞争型 RL 环境中的地位。

## 2. 关键技术节点对比表
| 版本 | 核心技术 | 改进动机 |
| :--- | :--- | :--- |
| v0.x | Gamecore 交互协议 | 解决 MOBA 游戏状态空间巨大、动作空间离散化的难题 |
| v1.0 | LSTM + 多头注意力 | 捕捉长时序的游戏状态变化，处理英雄、野怪、兵线等异构数据 |
| v2.0 | 分布式 Actor-Learner | 应对 3v3 模式下指数级增长的状态搜索空间，提升采样效率 |

## 3. 迭代动机分析
项目的演进旨在**从“单兵作战”向“团队协同”跨越**。早期版本侧重于验证深度学习在复杂 MOBA 游戏中的可行性，而后期通过引入 3v3 环境和集群训练框架，致力于解决多智能体强化学习（MARL）中的非平稳性与信用分配问题。
