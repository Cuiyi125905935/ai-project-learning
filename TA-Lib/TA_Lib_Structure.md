# TA-Lib 核心因子逻辑与结构拆解

## 1. 目录结构与模块对接
*   `src/ta_func/`: **C 底层计算模块**。包含 MACD、RSI 等因子的数学公式实现，是性能的核心保障。
*   `talib/`: **Python 接口封装**。提供 `talib.MACD()`, `talib.RSI()` 等简洁接口，直接输出 NumPy 数组。
*   **对接说明**: TA-Lib 输出的因子可直接作为 FinRL 的观测空间特征，或 LightGBM 的训练集列。

## 2. 常用选股因子逻辑拆解
| 类别 | 代表因子 | 计算逻辑与选股意义 |
| :--- | :--- | :--- |
| **趋势类** | MACD, EMA | 捕捉价格长期趋势。MACD 金叉通常被视为买入信号。 |
| **震荡类** | RSI, KDJ | 识别超买超卖。RSI > 70 为超买，< 30 为超卖，适合短线波段。 |
| **成交量类** | OBV, VOL | 量价配合分析。OBV 持续上升配合价格上涨，确认上涨趋势有效。 |

## 3. 参数调整对选股的影响
以 MACD 为例，将默认参数 `(12, 26, 9)` 调整为 `(5, 10, 3)` 可显著提升对 A 股短线波动的敏感度，但会增加假信号噪音。
