# HQChart 江恩工具适配与本地搭建说明

## 1. Windows 环境本地搭建步骤（适配 G 盘）
*   **第一步：源码拉取**
    将 HQChart 官方仓库克隆至 `G:\AI_Alchemy_System\lib\HQChart`。该库主要基于 JavaScript/Canvas，但在量化分析中我们重点关注其核心的几何计算逻辑。
*   **第二步：Python 接口配置**
    由于 HQChart 原生为前端组件，我们通过 Python 的 `subprocess` 或移植其核心算法公式来实现 CPU 运行。禁用所有 Canvas 渲染模块，仅保留 `GannAngle`, `SquareOfNine` 等数学模型。
*   **第三步：模块验证**
    编写测试脚本，输入标准价格序列，验证角度线斜率及轮中轮刻度的计算结果是否符合江恩理论基准。

## 2. 版本迭代与动态校准优化
*   **v2.0**: 实现了基础的江恩角度线绘制和四方形价格映射，支持静态参数输入。
*   **v3.0**: 引入“动态波动率校准模块”。模型能根据个股近 60 天的 ATR（平均真实波幅）自动调整 1x1 线的“时间-价格比率”，解决了科技股与蓝筹股在同一图表下比例失调的问题。同时升级了“轮中轮时间-价格映射”，支持 pmdarima 识别的非标准周期（如 30 天、45 天）。
