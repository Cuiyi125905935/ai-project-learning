# ChineseChess-AlphaZero 项目进化历程

## 1. 版本时间线
*   **初始阶段 (v0.1)**: 基础中国象棋规则实现，基于 `mm12432/MyChess` 引擎框架。
*   **MCTS 引入 (v0.5)**: 集成蒙特卡洛树搜索（MCTS），实现了 UCT 算法进行局面评估。
*   **AlphaZero 架构落地 (v1.0)**: 引入双头神经网络（策略头 + 价值头），开启自对弈训练流程。
*   **分布式优化 (v2.0)**: 拆分 `self` (自对弈), `opt` (训练), `sl` (监督学习), `eval` (评估) 四大模块，支持多机协同。

## 2. 关键技术节点对比表
| 版本 | 核心技术 | 改进动机 |
| :--- | :--- | :--- |
| v0.1 | 规则驱动 | 建立合法的动作空间与棋盘状态表示 |
| v0.5 | MCTS + 随机 rollout | 解决传统 Minimax 搜索深度受限问题 |
| v1.0 | CNN + ResNet | 利用深度学习自动提取棋盘特征，替代人工评估函数 |
| v2.0 | 分布式 Actor-Learner | 突破单机算力瓶颈，加速模型收敛 |

## 3. 迭代动机分析
项目的核心演进逻辑是**从“硬编码规则”向“数据驱动智能”的转变**。早期版本依赖人工编写的估值函数，而后期通过引入 AlphaZero 的自对弈机制，让模型在数千万次对局中自我进化，最终在 ELO 评分上超越传统引擎。
